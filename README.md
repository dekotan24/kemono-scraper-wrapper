# Kemono Scraper GUI

kemono-scraper のWindows GUI ラッパーアプリケーションです。

## 機能

- **アーティスト管理**: 複数のアーティスト（クリエイター）を登録・管理
- **一括実行**: 登録したアーティストを順番にダウンロード
- **差分ダウンロード**: 前回完了日時以降の投稿のみダウンロード（`--date-after`オプション使用）
- **batch_exec.batインポート**: 既存のバッチファイルからアーティストリストをインポート
- **URLからの追加**: kemono URLを貼り付けるだけでアーティストを追加
- **URL抽出ツール**: content.txt/htmlから外部ストレージのURLとパスワードを一括抽出
- **設定の永続化**: 全ての設定をJSONで保存、次回起動時に復元
- **リアルタイムログ表示**: ダウンロード状況をリアルタイムで表示

## 必要環境

- Windows 10/11
- .NET 6.0 Runtime（または.NET 6.0 SDK）
- kemono-scraper.exe（同じフォルダに配置するか、パスを設定）

## ビルド方法

```bash
# .NET 6.0 SDKが必要
dotnet build -c Release
```

または Visual Studio 2022 でソリューションを開いてビルド。

## 使い方

### 1. 初回設定

1. アプリを起動
2. 「パス設定」で `kemono-scraper.exe` のパスを指定
3. 「出力先」でダウンロードフォルダを指定（例: `Y:\kemono`）
4. 必要に応じてオプションを設定
5. 「設定保存」をクリック

### 2. アーティストの追加

**方法1: 手動追加**
- 「追加」ボタンをクリック
- サービスとクリエイターIDを入力

**方法2: URLから追加**
- テキストボックスにkemono URLを貼り付け（例: `https://kemono.cr/patreon/user/12345`）
- 「URL追加」をクリック

**方法3: バッチファイルからインポート**
- 「batインポート」ボタンをクリック
- 既存の `batch_exec.bat` を選択

### 3. 実行

- **選択実行**: アーティストを選択して「選択を実行」
- **一括実行**: 「全て実行」で有効な全アーティストを順番に実行

### 4. 差分ダウンロード

- 「差分DL」チェックボックスをONにすると、前回完了日時以降の投稿のみダウンロード
- 全件再ダウンロードしたい場合は、右クリックメニューから「完了日時をリセット」

### 5. URL抽出ツール

ダウンロード済みの投稿からMega、Google Drive等の外部ストレージURLとパスワードを一括抽出できます。

1. 「🔗 URL抽出」ボタンをクリック
2. 検索フォルダを選択（出力先フォルダが初期値）
3. 「抽出開始」をクリック
4. 結果は一覧表示 → CSVエクスポート or URLコピー可能

**対応サービス**: Mega, Google Drive, Dropbox, OneDrive, MediaFire, Gofile, Pixeldrain, Catbox, Bunkr, Cyberdrop, iwara.zip 等

**パスワード検出**: 「パスワード：」「Pass:」「解凍パス」等のパターンを自動検出

## オプション説明

| オプション | 説明 |
|-----------|------|
| Content | 投稿のテキスト内容をダウンロード（HTML/TXTファイル） |
| Banner | バナー画像をダウンロード |
| Async | 非同期（並列）ダウンロード |
| Overwrite | 既存ファイルを上書き |
| Prefix Number | ファイル名に番号プレフィックスを追加 |
| 差分DL | 前回完了日時以降の投稿のみダウンロード |

## データ保存場所

設定とアーティストリストは以下に保存されます：

```
%APPDATA%\KemonoScraperGUI\
├── settings.json    # アプリ設定
└── artists.json     # アーティストリスト
```
