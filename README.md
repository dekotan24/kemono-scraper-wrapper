# Kemono Scraper GUI

[kemono-scraper](https://github.com/dekotan24/kemono-scraper-customized) のWindows GUIラッパーアプリケーションです。

## 📋 機能

### メイン機能
* **アーティスト管理**: 複数のクリエイターを登録・管理
* **一括実行**: 登録したアーティストを順番に自動ダウンロード
* **差分ダウンロード**: 前回完了日時以降の投稿のみダウンロード（`--date-after`オプション使用）
* **リアルタイムログ表示**: ダウンロード状況をリアルタイムで確認
* **設定の永続化**: すべての設定をJSONで保存、次回起動時に自動復元

### アーティスト追加方法
1. **手動追加**: 「追加」ボタンからサービスとIDを入力
2. **URLから追加**: kemono URLを貼り付けるだけで自動追加
   - 例: `https://kemono.cr/patreon/user/12345`
3. **バッチファイルインポート**: 既存の`batch_exec.bat`からまとめて追加（内部向け）

### URL抽出ツール（🔗 URL抽出ボタン）
ダウンロード済みの投稿から外部ストレージのURLとパスワードを一括抽出できます。

**対応サービス**（全20種類以上）:
* ファイル共有: Mega, Google Drive, Dropbox, OneDrive, MediaFire
* アップローダー: Gofile, Pixeldrain, Catbox, Bunkr, Cyberdrop
* その他: Iwara.zip, Workupload, Krakenfiles 等

**機能**:
* 外部ストレージのURLを自動検出
* パスワードを自動抽出（日本語・英語対応）
* CSV出力機能
* URLの一括コピー
* URLを直接ブラウザで開く
* 元ファイルのフォルダを開く

## 📦 必要環境

* **OS**: Windows 10/11
* **ランタイム**: .NET 6.0 Runtime（または.NET 6.0 SDK）
* **スクレイパー**: [kemono-scraper.exe](https://github.com/dekotan24/kemono-scraper-customized)（ビルドして実行ファイルと同じフォルダに配置するか、パスを設定）

## 🔧 ビルド方法

### コマンドライン
```bash
# .NET 6.0 SDKが必要
dotnet build -c Release
```

### Visual Studio
Visual Studio 2022でソリューションを開いてビルド

## 🚀 使い方

### 1. 初回設定

1. アプリを起動
2. 「**パス設定**」で`kemono-scraper.exe`のパスを指定
3. 「**出力先**」でダウンロードフォルダを指定（例: `Y:\kemono`）
4. 必要に応じてオプションを設定
5. 「**設定保存**」をクリック

### 2. アーティストの追加

#### 方法1: 手動追加
* 「追加」ボタンをクリック
* サービスとクリエイターIDを入力

#### 方法2: URLから追加
* テキストボックスにkemono URLを貼り付け
  - 例: `https://kemono.cr/patreon/user/12345`
* 「URL追加」をクリック（またはEnterキー）

#### 方法3: バッチファイルからインポート（内部向け）
* 「batインポート」ボタンをクリック
* 既存の`batch_exec.bat`を選択

### 3. 実行

#### 個別実行
* アーティストを選択して「選択を実行」

#### 一括実行
* 「全て実行」で有効な全アーティストを順番に実行
* 実行中はキャンセルボタンで中断可能

### 4. 差分ダウンロード

*「**差分DL**」チェックボックスをONにすると、前回完了日時以降の投稿のみダウンロード
* 全件再ダウンロードしたい場合は、右クリックメニューから「**完了日時をリセット**」

### 5. URL抽出ツール（β）

1. 「**🔗 URL抽出**」ボタンをクリック
2. 検索フォルダを選択（出力先フォルダが初期値）
3. 「外部ストレージのみ」をチェック（推奨）
4. 「**抽出開始**」をクリック
5. 結果を確認
   - CSV出力: 「CSV出力」ボタン
   - URL一括コピー: 「全URLコピー」ボタン
   - 個別URL操作: 行を右クリック

## ⚙️ 設定オプション

### 基本オプション
| オプション | 説明 |
|----------|------|
| **Content** | 投稿のテキスト内容をダウンロード（HTML/TXTファイル） |
| **Banner** | バナー画像をダウンロード |
| **Async** | 非同期（並列）ダウンロード |
| **Overwrite** | 既存ファイルを上書き |
| **Prefix Number** | ファイル名に番号プレフィックスを追加 |
| **差分DL** | 前回完了日時以降の投稿のみダウンロード |

### 詳細設定
| 項目 | 説明 | デフォルト |
|-----|------|----------|
| **最大並列数** | 同時ダウンロード数 | 3 |
| **リトライ回数** | 失敗時の再試行回数 | 3 |
| **リトライ間隔** | 再試行までの待機時間（秒） | 10 |
| **レート制限** | リクエスト数/秒 | 2 |
| **タイムアウト** | ダウンロードタイムアウト（秒） | 1800 |
| **プロキシURL** | プロキシサーバー（オプション） | - |

### フィルター設定
| 項目 | 説明 | 例 |
|-----|------|-----|
| **テンプレート** | パステンプレート | - |
| **拡張子フィルター** | ダウンロードする拡張子（カンマ区切り） | `jpg,png,mp4` |
| **除外拡張子** | 除外する拡張子（カンマ区切り） | `txt,html` |
| **最大サイズ** | 最大ファイルサイズ | `100MB` |
| **最小サイズ** | 最小ファイルサイズ | `1KB` |

## 💾 データ保存場所

設定とアーティストリストは以下に自動保存されます：

```
%APPDATA%\KemonoScraperGUI\
├── settings.json    # アプリ設定
└── artists.json     # アーティストリスト
```

**注意**: ウィンドウ位置・サイズも自動保存されます

## 🎯 コンテキストメニュー（右クリック）

アーティストリストで右クリックすると以下の操作が可能：

* **実行**: 選択したアーティストを実行
* **編集**: アーティスト情報を編集
* **削除**: アーティストを削除
* **フォルダを開く**: ダウンロードフォルダを開く
* **URLをコピー**: kemono URLをクリップボードにコピー
* **完了日時をリセット**: 次回実行時に全件ダウンロード

## 📝 Tips

### 効率的な使い方
1. **差分DLを有効化**して定期的に実行すると、新規投稿のみ自動取得
2. **一括実行**で寝ている間に全アーティストをダウンロード
3. **URL抽出ツール**でダウンロード済み投稿から外部リンクをまとめて収集（contentファイルのダウンロードが必要）

### トラブルシューティング
* **ダウンロードが失敗する**: リトライ回数とタイムアウトを増やす
* **kemono-scraperが見つからない**: パス設定を確認
* **フォルダが見つからない**: まだダウンロードしていない可能性
